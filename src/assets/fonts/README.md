# Local fonts

Chinese text uses the system sans-serif stack. These Latin WOFF2 files are served locally by the site and use `font-display: swap`.

- `instrument-serif-latin-italic.woff2`: Instrument Serif Italic, Google Fonts v5. Used for the home signature and the quotation mark. [Font source](https://github.com/Instrument/instrument-serif), [download](https://fonts.gstatic.com/s/instrumentserif/v5/jizHRFtNs2ka5fXjeivQ4LroWlx-6zAjjH7M.woff2).
- `jetbrains-mono-latin.woff2`: JetBrains Mono variable font, Google Fonts v24. Used for code and small editorial labels. [Font source](https://github.com/JetBrains/JetBrainsMono), [download](https://fonts.gstatic.com/s/jetbrainsmono/v24/tDbv2o-flEEny0FZhsfKu5WU4zr3E_BX0PnT8RD8yKwBNntkaToggR7BYRbKPxDcwg.woff2).

Both fonts are distributed under the SIL Open Font License 1.1. Their copyright notices and full license texts are included alongside the font files. No third-party font service is contacted by the rendered site.
